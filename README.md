# CommerceHub

CommerceHub es una API backend desarrollada con ASP.NET Core para una plataforma de comercio electrónico.

El proyecto está pensado para gestionar productos, categorías, clientes, pedidos y otros procesos relacionados con una tienda que puede vender ropa, accesorios, joyas u otros tipos de productos.

## Objetivo

Este proyecto tiene como objetivo aplicar conceptos de desarrollo backend con .NET moderno mediante una aplicación real que irá creciendo progresivamente.

Durante el desarrollo se trabajarán temas como:

- ASP.NET Core Web API
- REST y HTTP
- Dependency Injection
- DTOs y validaciones
- async/await
- Entity Framework Core
- SQL Server
- LINQ
- Arquitectura y principios SOLID
- Testing con xUnit y Moq
- Autenticación y autorización
- Docker
- CI/CD
- Azure

## Tecnologías

- .NET 10
- C#
- ASP.NET Core Web API
- JetBrains Rider
- Git
- GitHub
